📐Как устроен адрес файла в Интернете

Каждый файл в сети Интернет имеет свой адрес — URL. Адрес всегда строится по одной и той же схеме из трёх частей: протокол, сервер и файл:

Протокол://Сервер/Файл.расширение

Часть адреса Что это Примеры
Протокол способ передачи данных http, https, ftp
:// разделитель после протокола всегда именно ://
Сервер адрес сайта (доменное имя) teach.ru, mail.com
/ разделитель перед именем файла одиночный слэш
Файл имя файла и его расширение inf.docx, data.htm
💡 Главная идея: в заданиях адрес разрезан на фрагменты, и их нужно просто расставить в порядке, заданном схемой: сначала протокол, сразу за ним ://, затем сервер, потом слэш / и в самом конце — имя файла с расширением. Порядок частей в адресе никогда не меняется.
⚠️ Важно: расширение файла всегда начинается с точки (.docx, .htm, .jpg) и стоит в адресе последним. Точка внутри доменного имени сервера (.ru, .com) относится к серверу, а не к файлу.

🔧Метод решения

1. Найдите в условии три главные части

Подчеркните в тексте: по какому протоколу осуществляется доступ, на каком сервере находится файл и как называется файл (вместе с расширением).

2. Запишите «скелет» адреса по схеме

Соберите адрес словами: протокол :// сервер / файл.расширение. Сначала делайте это без цифр, просто названиями частей — так проще не запутаться.

3. Замените каждую часть номером её фрагмента

Идите по списку фрагментов и подставляйте номера. Если сервер или файл собраны из двух фрагментов (например, teach и .ru) — номера идут подряд в том же порядке, что и кусочки внутри названия.

4. Проверьте себя сборкой

Прочитайте фрагменты в порядке полученных номеров — должен получиться осмысленный адрес, где :// стоит сразу после протокола, а расширение файла — в самом конце.

Условие задачи

Доступ к файлу inf.docx, находящемуся на сервере teach.ru, осуществляется по протоколу ftp. Фрагменты адреса файла закодированы цифрами от 1 до 7:

ЦифраФрагмент
1teach
2ftp
3inf
4/
5://
6.docx
7.ru
❓ Вопрос: запишите в ответе последовательность этих цифр, кодирующую адрес указанного файла в сети Интернет.

Шаг 1. Выписываем три части из условия

  • Протокол: ftp
  • Сервер: teach.ru
  • Файл: inf.docx

Шаг 2. Собираем скелет адреса по схеме

ftp://teach.ru/inf.docx

протокол → :// → сервер → / → имя файла → расширение

Шаг 3. Заменяем части номерами фрагментов

Часть адреса ftp :// teach .ru / inf .docx
Номер фрагмента 2 5 1 7 4 3 6

Шаг 4. Проверка сборкой

2 → 5 → 1 → 7 → 4 → 3 → 6
ftp + :// + teach + .ru + / + inf + .docx = ftp://teach.ru/inf.docx ✔

Получился осмысленный адрес: протокол ftp, сразу за ним ://, сервер teach.ru, слэш и файл inf.docx в конце.

💡Ключевые моменты при решении

1. :// идёт только после протокола

Фрагмент :// в адресе встречается один раз и всегда стоит на втором месте — сразу после протокола. Это лучшая «зацепка»: нашли протокол — следующий номер почти наверняка у ://.

2. Сервер может состоять из нескольких фрагментов

Доменное имя часто разрезано на части: teach + .ru, www + school + .ru. Все эти номера идут подряд, и внутри сервера слэша быть не может.

3. Расширение файла — всегда в конце

Фрагмент с точкой и буквами формата (.docx, .htm, .jpg) — последний в ответе. Не путайте его с точкой домена: .ru относится к серверу и стоит до слэша.

4. Слэш разделяет сервер и файл

Одиночный / стоит между доменным именем и именем файла. Если файл лежит в папке, слэшей может быть несколько: сервер/папка/файл — тогда слэш встретится в списке фрагментов дважды или будет отдельным фрагментом-папкой.

✅ Алгоритм решения любой задачи этой темы

  1. Выпишите из условия протокол, сервер и имя файла с расширением
  2. Соберите адрес по схеме: протокол → :// → сервер → / → файл.расширение
  3. Подставьте вместо каждой части номер её фрагмента
  4. Проверьте: прочитайте фрагменты по номерам — должен получиться правильный адрес
