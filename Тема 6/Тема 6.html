📐Условный оператор на разных языках

Условный оператор проверяет логическое условие и в зависимости от того, истинно оно или ложно, выполняет одну из двух ветвей: если... то... иначе.... В заданиях ОГЭ одна и та же программа часто дана сразу на пяти языках — Бейсик, Python, Паскаль, Алгоритмический язык и C++. Внешне код выглядит по-разному, но логика во всех случаях одинаковая.

Язык Конструкция «если...иначе» «ИЛИ» «И»
Бейсик IF ... THEN ... ELSE ... ENDIF OR AND
Python if ...: ... else: ... or and
Паскаль if ... then ... else ... or and
Алгоритмический язык если ... то ... иначе ... все или и
C++ if (...) { ... } else { ... } || &&
💡 Главное: не важно, на каком языке записана программа — важно правильно прочитать условие. Как только условие переведено в обычную математическую форму (например, s > 10 или t > A), дальше программа и язык больше не нужны.

🧭Визуальный метод решения

Типичное задание: дано условие с неизвестным параметром (например, A), набор пар входных значений и требование — сколько раз программа напечатает «YES» (или похожее условие на количество). Нужно найти, для скольких целых значений параметра это выполняется.

1️⃣ Запишите условие в обычном математическом виде

Переведите ключевые слова языка в привычные символы: OR/или/|| → «хотя бы одно из условий истинно», AND/и/&& → «оба условия истинны одновременно».

2️⃣ Разделите входные пары на две группы

Группа «всегда YES» — пары, где часть условия без параметра уже истинна сама по себе (результат не зависит от A).

Группа «зависит от A» — пары, где решение определяется только той частью условия, где участвует параметр.

3️⃣ Выпишите нужные неравенства для зависимой группы

Для каждой пары из зависимой группы запишите неравенство относительно A (например, t > A) и подставьте известное значение t — получится просто число, с которым сравнивается A.

4️⃣ Посчитайте, сколько «YES» нужно получить от зависимой группы

Вычтите количество «всегда YES» из общего требуемого количества «YES» — остаток должна обеспечить зависимая группа.

5️⃣ Отсортируйте числа и найдите диапазон для A

Расположите числа зависимой группы по возрастанию. Граница нужного количества «YES» находится между двумя соседними числами в этом ряду — там и лежит диапазон подходящих значений A.

6️⃣ Посчитайте целые числа в найденном диапазоне

Это и есть ответ на вопрос «сколько целых значений A подходит».

📌 Важно: строгое неравенство (>) и нестрогое (≥) дают разные границы — всегда проверяйте знак сравнения в условии.

🎯Разбор примера

Условие задачи

Программа на пяти языках проверяет условие для целых s, t, A:

если s > 10 или t > A  →  «YES», иначе  →  «NO»

Было проведено 9 запусков программы с парами значений (s; t):

(1, 2); (11, 2); (1, 12); (11, 12); (−11, −12); (−11, 12); (−12, 11); (10, 10); (10, 5)

Укажите количество целых значений параметра A, при которых для указанных входных данных программа напечатает «YES» ровно семь раз.

Шаг 1. Делим пары на «всегда YES» и «зависит от A»

Так как условие — это «s > 10 или t > A», результат точно будет «YES», если уже s > 10, независимо от A.

💡Ключевые моменты при решении

1️⃣ Язык программы не важен — важна логика условия

Сразу переведите код на любом из пяти языков в обычную запись с «если... иначе» и знаками сравнения — дальше работайте только с этой записью.

2️⃣ «ИЛИ» — ищите часть условия, которая не зависит от параметра

Если хотя бы одно слагаемое условия через «или» истинно само по себе (без параметра) — результат уже предрешён, и такую пару можно сразу отложить в группу «всегда YES» (или «всегда NO», если условие через «и»).

3️⃣ Строгие и нестрогие неравенства — разные границы

t > A и t ≥ A дают разный результат при t = A. Внимательно смотрите на знак в условии.

4️⃣ Считайте целые числа в диапазоне аккуратно

Если получили диапазон вида 2 ≤ A < 5, не забывайте, что левая граница включена, а правая нет — переберите значения вручную (2, 3, 4), чтобы не ошибиться.

✅ Алгоритм решения любой задачи этой темы

  1. Переведите условие программы в обычную математическую форму
  2. Разделите входные пары на «всегда YES/NO» и «зависит от параметра»
  3. Для зависимых пар запишите неравенства и подставьте известные числа
  4. Вычислите, сколько YES должна дать зависимая группа
  5. Отсортируйте числа, найдите граничный диапазон для параметра и посчитайте целые значения
